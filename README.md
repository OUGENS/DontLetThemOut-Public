# Don't Let Them Out

*Don't Let Them Out* is a fixed-path tower defense game set within a dark cavern chasm. Defend the surface world by eliminating subterranean creatures before they escape. 

> **Play Mode:** Best experienced in **Fullscreen Gameplay**.

---

## Play the Game
- **Itch.io WebGL Build:** [https://ougens.itch.io/dont-let-them-out](https://ougens.itch.io/dont-let-them-out)

---

## Key Features
- **Atmospheric Cave Environment:** Moody subterranean lighting featuring 12 distinct tower placement nodes.
- **10 Escalating Waves:** Hold off 3 enemy archetypes (Runners, Tanks, and a massive Wave 10 Boss).
- **3 Tactical Turret Types:**
  - **Ballista:** High-speed single-target bolts with target piercing.
  - **Cannon:** Heavy, high-damage artillery.
  - **Slow Turret:** Area-of-effect pulse dealing tick damage and slowing enemy movement.
- **In-Memory Game Loop:** Fast UI reset without full scene reloads.
- **Custom Engine Logic:** Built using custom vector movement and distance checks (no physics colliders/NavMesh).

---

## Controls
- **Left Click:** Select placement nodes, open build menus, buy, upgrade, or sell turrets.
- **ESC Key:** Toggle Pause Menu (Resume, Restart, Quit).
